This lab is a Python chatbot that runs locally on my computer by using the Groq API to generate responses. It saves user messages and assistant replies during each session so users can ask follow-up questions that refer to earlier parts of the conversation. The program can be installed and launched using the chat command, and users can exit with a keyboard interrupt or end-of-input. It also includes automated tests that use simulated inputs and replies to check conversation history, printed responses, and clean exits without contacting the API.
